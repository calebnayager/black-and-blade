# BLACK & BLADE | Modern Grooming

A responsive barber shop website built as a practical web development project using HTML, CSS, and JavaScript.

**Live Demo:** https://calebnayager.github.io/black-and-blade/ 

## Overview

BLACK & BLADE is a fictional premium barber shop based in Durban, South Africa.

The project focuses on creating a modern customer-facing website with responsive layouts, service information, barber profiles, contact information, and an interactive appointment booking experience.

The project was developed with a focus on **responsive design, usability, client-side functionality, and cross-device testing**.

## Features

* Responsive navigation and layouts
* Hero section and service highlights
* Services and pricing
* Barber profiles
* Interactive appointment booking
* Service and barber selection
* Appointment date and time selection
* Booking summary
* Appointment duration and closing-time validation
* Responsive design across mobile, tablet, and desktop screen sizes

## Development

The website was developed from the ground up with a focus on creating a consistent user experience across different screen sizes.

Responsive testing was performed across mobile, tablet, desktop, and larger display layouts. Issues identified during testing were iteratively debugged and refined.
